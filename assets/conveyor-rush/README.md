# Conveyor Rush – separate Codex-ready assets

This pack contains **one logical asset per PNG**, not sprite sheets.

Copy the whole `conveyor-rush` folder into your project's `assets/` directory.

## Integration rule
Use these files only as visual skins. Keep the existing `ConveyorRush` gameplay logic, `data-chute` carrier matching, pointer drag controller, scoring and hit targets.

## Folders
- `belt/` conveyor pieces
- `boxes/` parcel variants
- `labels/` blank shipping-label assets
- `carriers/` carrier badge plates
- `zones/` complete carrier chute visuals
- `states/` drag/drop feedback states
- `ui/` directional/guide graphics
- `decor/` optional Christmas/logistics decorations

See `manifest.json` for recommended mappings.
